nv 要求仕様

決定と用語

すべての要求のもとになる利用者の決定と用語。

決定(利用者)

  • uv のスタイルで使う(別の版の管理の道具(fnm など)を入れさせない)
  • wrangler-compose とは別の道具として作る。同じリポジトリに置く
  • Cloudflare に触れず、Wrangler を自分で動かさない(Wrangler を使わないプロジェクトでも使える)。wrangler-compose は、一緒に配る実行ファイルとスキルとしてだけ扱う
  • 個人の道具として wrangler-compose と 1 つのリポジトリにまとめ、更新(self update)とエージェント用のスキル(install skill)は nv に寄せる。nv が wrangler-compose の分も扱う
  • エージェント用のスキルは Claude Code と Codex に、利用者全体へ入れる。Codex 向けは共有の置き場 ~/.agents/skills/ に常に入れる
  • nv が利用者ごとに持つものは ~/.nv の下に置き、Node と道具の置き場は ~/.nv/cache に統一する(OS ごとに置き場所を変えない)
  • nv が動かす npm のキャッシュも ~/.nv/cache/npm に置き、利用者がほかで使う npm のキャッシュ(~/.npm など)と分け合わない(uv がパッケージのキャッシュを自分で持つのと同じ考え方)
  • GitHub の公開のリポジトリ yusukei/nv(個人)に置き、GitHub Actions で Release に OS ごとの実行ファイルを置く
  • 公開して配るので、更新の機能を持つ

用語

語意味
プロジェクトpackage.json を持つフォルダ。いまいるフォルダから上へたどって最初に見つかるもの
Node の版プロジェクトの .node-version に書いた、24.11.1 のような 3 つの数の版
nv のフォルダ利用者のホームの ~/.nv(Windows は %USERPROFILE%\.nv)。nv が利用者ごとに持つものは、すべてこの下に置く。利用者全体の設定などが要るようになったら、ここに置く
置き場nv が Node と道具を置くフォルダ。どの OS でも ~/.nv/cache
