wrangler-compose・nv

仕様書

このリポジトリは 2 つの道具を別々に作る。wrangler-compose は Cloudflare の環境を、nv は Node・npm を受け持つ。道具ごとに、何ができるべきかを書いた要求仕様と、それを満たす作りを書いた詳細仕様がある。

道具と文書

道具受け持つこと
wrangler-compose手元で開発したサービスを、安全にリモート(Cloudflare の環境)へ展開する。サービスは docker compose に寄せた compose ファイルに書き、--env <環境> up で手元にもリモートにも同じ形で建てる
nvNode・npm を uv のように扱う。Node の版の固定と取得、依存の導入、揃えた環境での実行、エージェント用のスキル

境目

  • wrangler-compose は Node・npm を自分で取らず、版も持たない。Wrangler と、Wrangler の版を調べる短いスクリプトを nv run wrangler … / nv run node … で動かす
  • nv は Cloudflare に触れず、Wrangler を自分で動かさない。wrangler-compose は、一緒に配る実行ファイルとスキルとしてだけ扱う
  • 2 つは同じフォルダに置き、wrangler-compose は同じフォルダの nv を使う
  • どちらも OS ごとの単体の実行ファイルで、1 つのリポジトリの同じ Release から同じ版で配る
  • 更新(nv self update)とエージェント用のスキル(nv install skill)は nv が 2 つ分まとめて受け持つ
