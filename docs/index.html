仕様書

このリポジトリは 2 つの道具を別々に作る。nv は Node・npm を、wrangler-compose は Cloudflare の環境を受け持つ。

道具受け持つこと文書
nv Node・npm を uv のように扱う。Node の版の固定と取得、依存の導入、揃えた環境での実行、エージェント用のスキル 要求仕様 / 受け入れ条件 / 設計
wrangler-compose Wrangler を docker compose のように扱う。環境を指定して build・up・down・backup・restore 要求仕様 / 受け入れ条件 / 設計 / 手元で使えないもの

境目

  • wrangler-compose は Node のことを何も知らず、Wrangler を nv run wrangler … で動かす
  • nv は Cloudflare に触れず、Wrangler を自分で動かさない。wrangler-compose は、一緒に配る実行ファイルとスキルとしてだけ扱う
  • 2 つは同じフォルダに置き、wrangler-compose は同じフォルダの nv を使う
  • どちらも OS ごとの単体の実行ファイルで、1 つのリポジトリの同じ Release から同じ版で配る
  • 更新(nv self update)とエージェント用のスキル(nv install skill)は nv が 2 つ分まとめて受け持つ
